Catalog Cache

Cache provider catalog metadata centrally so Panther can browse much faster.
▼
How it works: Panther uses one dedicated Xtream account per provider to cache Live TV, Movies, Series and optionally EPG metadata on Supabase. The Android app can then load those catalog lists from Panther's cache instead of making every device download the full provider library. Playback still uses each viewer's own IPTV login. The cache password is never returned to the app or shown again in this panel.

Private Library

Add content through Magnet Link / TorBox and control account access.
▼
Account-controlled library. Panther only shows the Private Library button after the current registered device's IPTV account is approved here. You can require a 4–8 digit PIN, set an expiry date, allow the whole library, or select individual titles. Only add material you are legally permitted to store and stream, and only make explicit material available to adults.

Adult Magnet / TorBox

Paste a magnet link, add it to TorBox, choose the video file, then publish it into Panther's existing Adult / Private Library.
NOT ADDED
Server-side TorBox import. The magnet link and TorBox API token are never sent to Panther devices. When a user presses Play, Panther receives a temporary protected playback URL and the Adult stream function redirects to TorBox's temporary CDN link. This keeps TorBox credentials out of the APK and avoids sending the video itself through Supabase.
